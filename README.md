# 🚀 موقع لَفَّة التعريفي — Laffah Showcase & Download Landing Page

موقع تعريفي عصري مصمم بأعلى معايير الويب يعرض مميزات تطبيق **"لَفَّة" (Laffah)** لمشاوير الدراجات النارية وتوصيل الطرود الفوري في صنعاء، مع خلفية سينمائية متحركة ومعرض شاشات تفاعلي، وزر تحميل مباشر لملف الـ APK، ودليل تثبيت خطوة بخطوة.

## ✨ المميزات الرئيسية للموقع
- **خلفية سينمائية تفاعلية:** جسيمات مضيئة وانعكاسات ألوان عضوية متدفقة تعكس الهوية البصرية لتطبيق لَفَّة.
- **معرض شاشات متكامل (7 شاشات):** استعراض حقيقي لرحلة الراكب والكابتن والمحفظة الرقمية.
- **دليل التثبيت السريع (3 خطوات):** شرح مبسط لتخطي تنبيه الحماية الروتيني في نظام أندرويد.
- **أسئلة شائعة (FAQ Accordion):** إجابات على استفسارات المستخدمين حول التكلفة، الأمان، وتطبيق الآيفون.
- **مشاركة سريعة للأصدقاء:** زر تفاعلي يتيح مشاركة الرابط مباشرة عبر واتساب ومختلف المنصات.
- **دعم وملاحظات فورية:** زر شات واتساب مباشر على الرقم الرسمي `+967770291452`.
- **توافق 100% مع الهواتف:** تصميم انسيابي فائق السرعة والخفة حتى مع سرعات الإنترنت المحدودة.
